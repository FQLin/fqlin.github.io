InteractionAttachController 官方文档中文注释版

本文档仅围绕 Unity 官方 interaction-attach-controller.md 进行翻译和注释。

文档来源

  • Unity 包版本：com.unity.xr.interaction.toolkit 3.4.1
  • 官方原文：

Library/PackageCache/com.unity.xr.interaction.toolkit@4612b35e2aac/Documentation~/interaction-attach-controller.md

1. 它是什么

官方原意翻译

这是 IInteractionAttachController 的默认实现。它可以用来控制 attach transform 的平移和旋转。

它通常和 NearFarInteractor 一起使用，用于处理远距离交互、被选中对象的稳定，以及以加速方式把远处物体拉向用户。

这个类还带有一种相对于 XROrigin 的平滑选项，可以让远距离抓取对象在玩家移动时仍保持更一致的平滑效果。

更重要的是，默认的稳定和平滑配置主要只作用于“带偏移”的远距离抓取对象，从而保证当对象切回近距离交互时，物体相对手或控制器的延迟尽量小。

更容易理解的注释

  • 如果把 NearFarInteractor 理解成“总控”，那 InteractionAttachController 就是“附着点运动规则执行器”。
  • 它不直接决定你选中了谁。
  • 它决定的是：选中之后，这个“附着点”怎么跟手、怎么平滑、怎么推拉、怎么旋转。

一句话记忆：

InteractionAttachController 决定“远距离选中后的物体手感”。

2. 官方属性表中文翻译

属性中文说明更容易理解的注释
Transform To Follow附着锚点要跟随的 transform。通常就是控制器或某个稳定锚点。
Motion Stabilization Mode附着锚点位置和旋转的稳定模式。控制“更稳”还是“更灵”。
Position Stabilization位置稳定因子，表示在多大距离范围内施加稳定效果。值越大，稳定作用范围越明显。
Angle Stabilization角度稳定因子，表示在多大角度范围内施加稳定效果。值越大，旋转也会更稳。
Smooth Offset是否在 XROrigin 空间里对偏移做平滑。适合远距抓物更自然。
Smoothing Speed平滑速度。值大时更快收敛到稳定状态。
Use Distance Based Velocity Scaling是否按距离缩放速度。远的物体可以更快拉动，不会显得拖。
Use Manipulation Input是否允许通过输入轴操控附着点。决定摇杆能不能直接操控选中物体。
Manipulation Input用来操控附着点的输入。一般对应摇杆。
X-axis ModeX 轴输入控制什么。左右输入是平移还是旋转。
Y-axis ModeY 轴输入控制什么。上下输入是推拉还是旋转。
Combine Manipulation Axes是否允许同时使用两个轴。关掉后会更“单一明确”，开着更自由。
Translate Speed平移速度。推拉快慢。
Rotate Speed旋转速度。旋转快慢。
Rotate Reference Frame旋转时使用的参考坐标系。决定“绕谁转、按哪个方向转”。
Use Momentum是否使用动量。推拉后可以有惯性。
Decay: Physical Movement由物理推拉触发时的动量衰减。值越大，惯性越快消失。
Decay: Input由输入轴触发时的动量衰减。值越大，摇杆松手后停得更快。
Z Velocity Ramp Threshold按 z 轴速度偏差缩放附加速度。影响前后方向推拉速度曲线。
Pull Velocity Bias调整向用户拉近时的速度计算。控制“拉近时有多快”。
Push Velocity Bias调整远离用户时的速度计算。控制“推出去时有多快”。
Min Additional Velocity Scalar运动附加速度最小值。控制最低额外加速。
Max Additional Velocity Scalar运动附加速度最大值。控制最高额外加速。

3. 在当前项目里怎么理解它

场景 1：首页

首页主要是点按钮，所以它的重要性没有模型交互时那么高。

你只需要知道：

  • 它仍然存在于 NearFarInteractor 结构里
  • 但首页的主要价值在 UI 射线，不在远距抓物手感

场景 2：质量评价

这里它就非常关键了。

因为你后面需要：

  • 选中点云模型
  • 控制模型旋转
  • 控制模型缩放或推拉
  • 保证选中后的模型不抖

这几个体验都和它直接相关。

场景 3：JND

如果 JND 场景更多偏向点选、确认和轻量对比，那它的重要性会略低于质量评价场景。
但只要你允许远距选中模型并做轻度操控，它仍然是关键组件。

4. 最值得先调的参数

如果你后面开始调手感，优先看这几个：

  • Use Manipulation Input
  • Manipulation Input
  • Translate Speed
  • Rotate Speed
  • Smooth Offset
  • Use Distance Based Velocity Scaling

推荐理解方式：

  • 先决定“要不要让摇杆控制模型”
  • 再决定“推拉和旋转速度”
  • 最后再调“稳不稳、柔不柔”

5. 一个容易误解的点

官方 near-far-interactor.md 提到：

NearFarInteractor 还不支持像 XRRayInteractor 那样直接使用摇杆控制 attach transform

但从新版 Starter Assets 的工程实践看：

  • 摇杆操控能力并没有真的完全消失
  • 它更多被放到了 InteractionAttachController 的输入操控逻辑里

所以在项目落地上，更准确的理解应该是：

新版不是把“操控 attach transform”这个能力删掉了，而是把它从旧的 XRRayInteractor 心智模型，转移到了 InteractionAttachController 这一层。

6. 调试建议

如果模型远程选中后体验很奇怪，优先看这里：

  • 模型是否突然飞到面前
  • 模型是否抖动明显
  • 推拉是否太慢
  • 旋转是否太快或太慢
  • 松开摇杆后是否还在“飘”

这些问题大概率都和它的参数设置有关。

7. 一句话结论

InteractionAttachController 不是“负责命中”的组件，而是“负责手感”的组件。
你后面要把点云模型操控做顺手，它会是最值得反复调的组件之一。
