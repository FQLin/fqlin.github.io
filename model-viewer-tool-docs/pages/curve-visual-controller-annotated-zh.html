CurveVisualController 官方文档中文注释版

本文档仅围绕 Unity 官方 curve-visual-controller.md 进行翻译和注释。

文档来源

  • Unity 包版本：com.unity.xr.interaction.toolkit 3.4.1
  • 官方原文：

Library/PackageCache/com.unity.xr.interaction.toolkit@4612b35e2aac/Documentation~/curve-visual-controller.md

1. 它是什么

官方原意翻译

CurveVisualController 是一个用于控制 LineRenderer 的可配置组件。它基于实现了 ICurveInteractionDataProvider 的交互器所提供的数据，生成一条可视化曲线。

它会结合可配置的起点、方向，以及来自曲线数据提供者的终点数据，生成一条贝塞尔曲线，用来掩盖不同起点之间的差异，也能掩盖某些稳定化处理带来的视觉偏差。

这个组件还允许根据曲线数据提供者的状态动态调整线条视觉属性，例如：

  • 命中 UI
  • 命中普通可交互对象
  • 处于选中状态
  • 没有命中有效目标

这样就可以按状态动态改变线条颜色、宽度、弯曲程度等。

更容易理解的注释

  • 它的职责非常纯粹：把线画出来，而且根据交互状态把线画得更清楚。
  • 它不负责命中逻辑。
  • 它不负责决定能不能选中物体。

一句话记忆：

CurveVisualController 负责“看起来像不像一条好用的 XR 射线”，不负责“到底有没有打中”。

2. 官方主要能力翻译

官方列出的能力包括：

  • 支持不同线条动态模式，如 Traditional、RetractOnHitLoss、ExpandFromHitPoint
  • 可自定义视觉设置，例如曲线点数、最大曲线距离
  • 可控制线条收缩、扩展、回弹等动态效果
  • 支持复杂曲线中点计算与吸附选项
  • 可根据不同状态切换颜色渐变
  • 可按不同终点类型定制线条属性
  • 可在“空命中”时切换材质，避免深度冲突
  • 能在可能的情况下使用 Burst 加速复杂曲线数学计算

更容易理解的注释

这意味着：

  • 它不只是“画一条固定激光”
  • 它可以根据你当前有没有打到目标、打到的是 UI 还是 3D 对象、是不是按下状态，自动换视觉表现

3. 官方属性表中文翻译

属性中文说明实际理解
Line Renderer要控制的 LineRenderer。真正显示线条的渲染器。
Curve Visual Object用来生成可视曲线的数据源。一般来自 NearFarInteractor 这类实现了曲线数据接口的对象。
Override Line Origin是否覆盖默认线起点。可以强行指定线从哪里出发。
Line Origin Transform自定义起点和方向的 transform。线头从哪发出来。
Customize Line Properties For State是否按状态定制线条属性。命中不同目标时换不同样式。
Line Property Animation Speed状态切换时线宽变化速度。控制视觉过渡是否顺滑。
No Valid Hit Properties无有效命中时的线条样式。没点到东西或点到不可交互物体。
UI Hit Properties命中 UI 时的线条样式。例如按钮高亮时的视觉。
UI Press Properties按下 UI 时的线条样式。例如点击按钮时的反馈。
Hover Hit Properties命中普通 3D 可交互对象时的线条样式。对模型悬停时的视觉。
Select Hit Properties已经成功选中时的线条样式。抓住/选中后的视觉。

4. Line Properties 表中文翻译

属性中文说明实际理解
Smoothly Curve Line当前状态下是否平滑弯曲线条。关掉就可能更接近直线。
Line Bend Ratio控制线条弯曲程度的比例。1 更接近直线，越偏离越明显。
Adjust Width是否修改默认线宽。按状态改粗细。
Start Width起点宽度。线头粗细。
End Width终点宽度。线尾粗细。
End Width Scale Distance Factor是否按长度比例缩放末端宽度。线越长末端可以越细或越粗。
Adjust Gradient是否修改默认颜色渐变。按状态换颜色。
Gradient当前状态使用的颜色渐变。例如正常蓝色、按下绿色。
Customize Expand Line Draw Percent是否自定义扩展模式的绘制比例。只在特定线动态模式下更重要。
Expand Mode Line Draw Percent扩展模式下绘制线条的百分比。控制扩展动画长度。

5. Advanced Properties 表中文翻译

属性中文说明实际理解
Visual Point Count生成曲线的点数。越多越平滑，也越重。
Max Visual Curve Distance可视曲线最大距离。线最长能画多远。
Resting Visual Line Length未伸出或未收回时的默认长度。射线待机时显示长度。
Compute Mid Point With Complex Curves是否为复杂曲线计算中点。主要影响更复杂曲线形态。
Snap To Selected Attach If Available如有可用附着点，线是否吸附到该点。选中后线头更贴合对象。
Snap To Snap Volume If Available如有 Snap Volume，线是否吸附。吸附点更明确。
Curve Start Offset曲线起点偏移量。防止线从控制器内部穿出来。
Curve End Offset曲线终点偏移量。防止线尾和目标重叠。
Render Line In World Space是否在世界空间渲染线。高速移动下如果有伪影，可以尝试切换。
Extend Line To Empty Hit空命中时是否也伸出线。没打到有效对象时，线还要不要延展出去。
Extension Rate线伸长速度。0 表示立刻伸到位。
Line Dynamics Mode线的动态模式。影响线的“呼吸感”和收放方式。
Retract Delay开始回缩前的延迟。控制命中丢失后的反馈节奏。
Retract Duration完全回缩所需时间。控制回缩快慢。
End Point Expansion Rate终点扩张/回缩速度。影响线尾动画。
Swap Materials是否按状态切换材质。处理无效命中时的特殊材质。
Normal Line Material正常材质。平时使用。
Empty Hit Material空命中材质。打到无效 3D 几何时使用。

6. 对当前项目最重要的理解

首页

首页主要关心：

  • 线有没有清晰地指示按钮
  • 悬停和按下时视觉有没有明显反馈

质量评价 / JND

这两个场景还要关心：

  • 命中模型时线条是否和命中状态区分明显
  • 选中后线条是否稳定
  • 线条长度、颜色和宽度是否不会干扰观察点云

对你的项目，我会更建议：

  • 线条颜色不要太艳，不要喧宾夺主
  • UI 命中与模型命中要有区分
  • 选中状态要清楚，但不要过于闪烁

7. 调试建议

如果你遇到这些现象：

  • 线看起来怪怪的
  • 线头像是插进模型里
  • 选中前后线条状态变化不明显
  • 线在高速移动时有拖影或跳动感

优先检查：

  • Curve Start Offset
  • Curve End Offset
  • Visual Point Count
  • Render Line In World Space
  • 不同状态的 Line Properties

8. 一句话结论

CurveVisualController 决定的是“射线好不好看、状态清不清楚”，
不是“能不能打中目标”。
把它理解清楚后，你调 XR 射线体验会轻松很多。
