Home 场景里，真正负责“射线打出去并与 UI/模型发生交互”的组件是 XR Ray Interactor，不是 XR Interactor Line Visual。

它现在挂在这两个对象上：

  • 左手控制器：HomeScene.unityD:/项目/点云主观实验平台VR/ModelViewerTool/新版本Unity项目/ModelViewerTool/Assets/Scenes/HomeScene.unity:739 里的 LeftHand Controller，对应的 XR Ray Interactor 在 HomeScene.unityD:/项目/点云主观实验平台VR/ModelViewerTool/新版本Unity项目/ModelViewerTool/Assets/Scenes/HomeScene.unity:1043
  • 右手控制器：HomeScene.unityD:/项目/点云主观实验平台VR/ModelViewerTool/新版本Unity项目/ModelViewerTool/Assets/Scenes/HomeScene.unity:1373 里的 RightHand Controller，对应的 XR Ray Interactor 在 HomeScene.unityD:/项目/点云主观实验平台VR/ModelViewerTool/新版本Unity项目/ModelViewerTool/Assets/Scenes/HomeScene.unity:1677

XR Interactor Line Visual 只是把那条射线画出来，不负责真正的命中和交互逻辑。

这个组件里各属性的作用
左右手这两个 XR Ray Interactor 现在配置几乎一样，我按你场景里的当前配置解释：

  • Interaction Manager：交互管理器。留空时通常自动找场景里的 XR Interaction Manager。
  • Interaction Layers：这条射线能和哪些交互层的对象交互。你这里是全开。
  • Handedness：手性标记，给系统区分左手/右手用。
  • Attach Transform：抓取或选中后，物体“附着”的参考点。留空会自动生成/使用默认附着点。
  • Keep Selected Target Valid = 1：选中后即使射线暂时没继续打到目标，也尽量保持这次选中有效。
  • Disable Visuals When Blocked In Group = 1：如果被交互组里的别的交互器挡住，就把当前可视反馈关掉。
  • Starting Selected Interactable：场景一开始默认就被选中的对象。你这里为空。
  • Starting Target Filter / Starting Hover Filters / Starting Select Filters：启动时附加的目标过滤器。你这里都没配。
  • Hover Entered / Hover Exited / Select Entered / Select Exited：悬停和选中时触发的事件回调。你这里都没绑。

输入相关

  • Select Input：选中输入。通常对应扳机/Grip 的“选中”动作。
  • Activate Input：激活输入。通常对应次级动作，比如按住后触发对象自己的功能。
  • Select Action Trigger = 1：决定 Select 用“状态变化”还是“保持按住”之类的触发方式。
  • Allow Hovered Activate = 0：没选中时，单靠悬停不允许发 Activate。
  • Hide Controller On Select = 0：选中时不隐藏控制器模型。

射线/轨迹相关

  • Line Type = 0：直线射线。不是抛物线，也不是贝塞尔曲线。
  • Blend Visual Line Points = 1：让显示出来的线更贴合当前控制器姿态，减少“线尾巴跟不上手”的感觉。
  • Max Raycast Distance = 30：直线射线最长 30。
  • Ray Origin Transform：射线从哪里发出。留空时用默认附着点/控制器位姿。
  • Reference Frame：曲线射线时的参考坐标系。你现在是直线，所以基本不生效。
  • Velocity / Acceleration / Additional Ground Height / Additional Flight Time / End Point Distance / End Point Height / Control Point Distance / Control Point Height：这些主要给抛物线/贝塞尔曲线用。你当前直线模式下基本不用。
  • Sample Frequency = 20：曲线采样点数量。直线模式影响很小。
  • Hit Detection Type = 0：命中检测方式是 Raycast。不是球投射也不是锥投射。
  • Sphere Cast Radius = 0.1：只有 SphereCast 时才重要。
  • Cone Cast Angle = 6：只有 ConeCast 时才重要。
  • Live Cone Cast Debug Visuals = 0：不显示锥投射调试图。

碰撞/命中过滤

  • Raycast Mask = 全部层：对所有 Layer 都可以做射线检测。
  • Raycast Trigger Interaction = 1：是否命中 Trigger Collider 的策略。
  • Raycast Snap Volume Interaction = 1：是否把 Snap Volume 这类触发体也算进来。
  • Hit Closest Only = 0：不是只取最近一个目标，允许多目标 hover。

悬停自动选中

  • Hover To Select = 0：不会只靠悬停一段时间就自动选中。
  • Hover Time To Select = 0.5：如果将来开启自动选中，需要悬停 0.5 秒。
  • Auto Deselect = 0：不会自动取消选中。
  • Time To Auto Deselect = 3：如果以后开启自动取消，持续 3 秒后取消。

UI 交互

  • Enable UI Interaction = 1：允许这条射线像鼠标一样点 World Space UI。
  • Block Interactions With Screen Space UI = 0：不会因为被屏幕空间 UI 挡住就禁用 3D 交互。
  • Block UI On Interactable Selection = 1：当这条射线已经在选中一个交互物体时，会阻止它再去点 UI。
  • UI Hover Entered / UI Hover Exited：进入/离开 UI 时的事件。你这里没绑。
  • UI Press Input：点 UI 按钮时用的输入。
  • UI Scroll Input：滚动 UI 列表时用的输入。

选中后沿射线操控物体

  • Manipulate Attach Transform = 1：允许用摇杆去调“附着点”，也就是让被选中的物体沿射线前后移动、旋转，甚至缩放。
  • Use Force Grab = 0：不是强制把物体瞬间拉到手边，而是保留远距离交互风格。
  • Rotate Speed = 180：旋转速度。
  • Translate Speed = 1：沿射线前后推拉的速度。
  • Rotate Reference Frame：旋转参考坐标系。留空时用默认。
  • Rotate Mode = 0：按“持续旋转”模式处理，不是“摇杆方向直接匹配朝向”。
  • Translate Manipulation Input：沿射线前后移动物体的输入。
  • Rotate Manipulation Input：旋转物体的输入。
  • Directional Manipulation Input：按方向匹配旋转时使用的输入。
  • Scale Mode = 0：当前缩放模式关闭。
  • Scale Toggle Input / Scale Over Time Input：切换到缩放或持续缩放时使用的输入。现在保留了输入槽，但因为 Scale Mode = None，默认不生效。

AR 相关

  • Enable AR Raycasting = 0
  • Occlude AR Hits With 3D Objects = 0
  • Occlude AR Hits With 2D Objects = 0

这些是给 AR 场景准备的，你这个 Oculus VR Home 场景基本用不到。
