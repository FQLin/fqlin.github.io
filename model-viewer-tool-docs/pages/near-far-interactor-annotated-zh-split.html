NearFarInteractor 官方文档中文注释版（拆分版）

本文档仅围绕 Unity 官方 near-far-interactor.md 进行翻译和注释，不再把其他文档混进来，方便单独查阅。

文档来源

  • Unity 包版本：com.unity.xr.interaction.toolkit 3.4.1
  • 官方原文：

Library/PackageCache/com.unity.xr.interaction.toolkit@4612b35e2aac/Documentation~/near-far-interactor.md

1. 它是什么

官方原意翻译

NearFarInteractor 是一种同时使用近距离交互探测器和远距离交互探测器的 Interactor。它允许在不同交互方式之间平滑切换，同时还能利用远距离交互探测器的数据与 UGUI 交互。

这个 Interactor 在设计上强调模块化和可扩展性。开发者可以实现自定义的近距离探测器和远距离探测器，它们分别需要遵循 IInteractionCaster 和 ICurveInteractionCaster 接口。

IInteractionAttachController 接口允许开发者实现自定义附着控制器，用于控制 attach transform 的平移和旋转。默认实现支持基于距离的速度缩放，可以把远处物体拉向用户，同时兼容手势跟踪和控制器跟踪。

为了配合这个 Interactor，官方还提供了一个可视化控制组件 CurveVisualController。它通过 ICurveInteractionDataProvider 提供曲线所需的数据，从而灵活地显示交互曲线。

这个 Interactor 的目标是整合 XRDirectInteractor 和 XRRayInteractor 的功能，但目前需要注意两个限制：

  • 在移动端 AR 设备上，仍然需要 XRRayInteractor 进行 AR 射线检测。
  • 官方文档写的是：NearFarInteractor 目前还不支持像 XRRayInteractor 那样直接用摇杆控制 attach transform 的平移、旋转和缩放。

更容易理解的注释

  • 它本质上是新版 XRI 的“统一交互器”。
  • 老写法常常是：

一个 XRDirectInteractor 负责近距离抓取，
一个 XRRayInteractor 负责远距离射线。

  • NearFarInteractor 则把它们合成到一套结构里。

可以把它记成一句话：

NearFarInteractor 负责“近距交互、远距交互、UI 射线交互，以及远距选中后的附着行为”。

2. 它不等于“那条线”

这点非常重要。

  • NearFarInteractor 不是那条可见射线本身。
  • 可见的线通常由 CurveVisualController + LineRenderer 负责。
  • 真正决定是否命中对象、是否能选中对象的，是 NearFarInteractor 以及它依赖的 Near/Far Caster。

所以如果你看到线画出来了，但按钮点不到、模型选不中，优先检查：

  • 输入动作
  • UI 配置
  • Collider
  • Interactable
  • Interaction Layer Mask
  • Far/Near Caster

而不是先怀疑线条显示组件。

3. 官方属性表中文翻译

属性中文说明实际理解
Interaction Manager当前 Interactor 通信的 XR Interaction Manager，空则自动查找。场景总交互管理器。
Interaction Layer Mask只与交互层有重叠的 Interactable 发生交互。这是 XR 交互层，不是普通 Unity Layer。
Select Action Trigger定义选中由哪种输入方式触发。决定选中是按住、切换还是其他模式。
Keep Selected Target Valid初次选中后，即使不再触碰或指向，也继续保持选中。抓物时通常建议开。
Allow Hovered Activate无选中时，允许对仅悬停对象发送激活/取消激活事件。偏次级动作配置。
Target Priority Mode决定 Targets For Selection 中追踪多少目标。偏高级反馈和性能控制。
Starting Selected Interactable启动时自动选中的对象。一般不用。
Parent Interactable可选父级 Interactable 依赖。偏高级。
Auto Find Parent Interactable自动向上查找父级 Interactable。省事的默认行为。
Interaction Attach Controller控制 attach transform 的附着控制器。决定远距选中后物体怎么跟随。
Enable Near Casting是否启用近距离探测。决定是否支持近距抓取/靠近交互。
Near Caster近距离探测组件。常见是 SphereInteractionCaster。
Sorting Strategy近距命中多个目标时的排序策略。决定“优先算碰到谁”。
Sort Near Targets After Target Filter是否在目标过滤后再次排序近距目标。进阶项。
Enable Far Casting是否启用远距离探测。决定能不能打远程射线/曲线。
Far Caster远距离探测组件。常见是 CurveInteractionCaster。
Far Attach Mode远距离选中时附着点如何调整。决定物体留在远处还是拉到手边。
UI Interaction是否允许与 UI 交互。点 World Space UI 时必须开。
Block UI On Interactable Selection选中 3D 对象时是否阻止 UI 交互。防止抓物时误点 UI。
UI Press InputUI 按下输入。类似鼠标左键。
UI Scroll InputUI 滚动输入。类似鼠标滚轮。
Select Input选中 Interactable 的输入。常对应扳机或 Grip。
Activate Input激活 Interactable 的输入。常作为第二动作。

4. 两个最关键的枚举

Region

官方含义：当前选择属于哪种交互区域。

  • None：当前没有选择
  • Near：当前是近距离选择
  • Far：当前是远距离选择

更容易理解的注释：

  • 它用来区分“这次交互更像手边抓到的”还是“远处射线选中的”。
  • 后面做提示、做状态动画时很好用。

InteractorFarAttachMode

官方含义：远距离选中时如何调整 attach transform。

  • Near：附着点回到近处，通常会把物体拉到手边
  • Far：附着点留在远处命中位置，通常物体继续待在远处

对当前项目的建议：

  • 首页按钮点击：这一项影响不大
  • 点云模型展示与操控：通常更推荐 Far

原因：

  • 你更希望模型留在展示位置
  • 不希望它一下飞到头前，破坏实验观感

5. 官方 Usage 部分翻译

这个组件应该挂载在一个作为 Interactor 使用的 GameObject 上。

完整功能依赖：

  • 一个实现 IInteractionAttachController 的组件
  • 一个实现 IInteractionCaster 的近距离探测组件
  • 一个实现 ICurveInteractionCaster 的远距离探测组件

如果 Interaction Attach Controller、Near Caster 或 Far Caster 为空，运行时会自动补上默认实现。

更容易理解的注释

虽然官方支持“缺了就自动补”，但项目实践里更建议：

  • 直接用 Starter Assets 的 Left_NearFarInteractor
  • 直接用 Starter Assets 的 Right_NearFarInteractor
  • 或者你自己显式把这几个组件挂完整

这样有两个好处：

  • 编辑器里一眼就能看清当前配置
  • 出问题时更容易排查

6. 在当前项目里的使用建议

Home 场景

目标：

  • 射线点首页按钮
  • UI 跟着视角

建议：

  • Enable UI Interaction = true
  • Enable Far Casting = true
  • Canvas 为 World Space
  • Canvas 上有 TrackedDeviceGraphicRaycaster
  • 场景里有 EventSystem + XRUIInputModule

质量评价场景

目标：

  • 点 UI
  • 远距离选中模型
  • 旋转、缩放、重置模型

建议：

  • 近距和远距都打开
  • Far Attach Mode = Far
  • 模型根对象有 Collider
  • 模型根对象有 XRGrabInteractable 或项目自定义交互脚本

JND 场景

建议：

  • 以“稳定点选”和“远距确认”为主
  • 如果不是重点做自由抓取，优先确保 UI 点击和远距选择稳定

7. 最常见误区

误区 1：把 XR 交互层和 Unity 物理层当成一回事

不是一回事。

  • Interaction Layer Mask 决定交互逻辑允许不允许
  • Raycast Mask / Physics Layer 决定射线能不能先打到 Collider

误区 2：有线就一定能点到

不一定。

看到线，只能说明“可视化正常”；
能不能点中，还要看输入、UI 模块、Canvas 和 Caster 配置。

误区 3：模型挂了 Mesh 就能选中

不行。

一般还需要：

  • Collider
  • Interactable
  • 正确的 Layer 和 Mask

8. 一句话结论

如果你准备在新版 Unity/XRI 里做 VR 射线交互，NearFarInteractor 是值得作为主方案使用的。
它特别适合你这种既要点 UI，又要操作空间中模型的项目。
